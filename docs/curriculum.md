# Currículo y ampliación

| Unidad             | Resultado observable                                            | Práctica                             |
| ------------------ | --------------------------------------------------------------- | ------------------------------------ |
| 1 · Comienzo       | Explicar Java y JVM, verificar un JDK y ejecutar Hola, mundo    | Historia, plataformas y terminal     |
| 2 · Lenguaje       | Elegir tipos, calcular, transformar texto y convertir entradas  | Variables, operadores y validaciones |
| 3 · Control        | Implementar decisiones y repeticiones con condiciones de salida | Juego de adivinanzas                 |
| 4 · Descomposición | Extraer métodos y procesar arrays con casos frontera            | Calculadora                          |
| 5 · Objetos        | Modelar estado, validar creación y usar contratos               | Clases, herencia e interfaces        |
| 6 · Proyecto       | Usar colecciones, errores y responsabilidades separadas         | Gestor de tareas                     |

Cada unidad tiene cinco lecciones. Cada lección incluye explicación, ejemplo ejecutable, ejercicio, pista, referencia de solución y evaluación. Los textos ES/EN comparten ID y ejemplos para conservar el progreso entre idiomas.

## Próximas entregas

1. Git, construcción con Maven/Gradle, JUnit y organización profesional.
2. Genéricos, archivos, lambdas y streams.
3. SQL y MySQL, instalación y JDBC: proyecto biblioteca persistente.
4. ORM, Jakarta Persistence e Hibernate: migrar el acceso a datos.
5. HTTP, JSON, Spring Boot, Spring Data JPA, REST, validación y pruebas: API de biblioteca.
6. Autenticación y React + API Java + MySQL: aplicación completa reproducible.

Cada módulo debe publicar instalación, comandos, resultados esperados, problemas frecuentes y proyecto guiado en ambos idiomas antes de dejar de figurar como próximamente. Esas rutas no forman parte del contenido terminado de la versión inicial.
