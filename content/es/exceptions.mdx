Una excepción representa una situación que rompe el flujo normal. `try` contiene una operación que puede fallar; `catch` maneja un tipo concreto. Captura lo que sabes resolver y no ocultes errores con bloques vacíos.

`finally` ejecuta limpieza incluso si hay una excepción. Para recursos que implementan AutoCloseable, estudiarás try-with-resources. Las excepciones no sustituyen validaciones normales: comprueba argumentos antes de operar cuando sea posible.

## Observa y ejecuta

```java
public class Main {
    public static void main(String[] args) {
        try {
            int n=Integer.parseInt("abc");
            System.out.println(n);
        } catch(NumberFormatException e) {
            System.out.println("Escribe un número válido");
        }
    }
}
```
