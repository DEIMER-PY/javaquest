Instala un JDK desde un proveedor oficial como Eclipse Temurin. Usa JDK 21 para los proyectos locales de esta ruta y consulta la guía de herramientas para Windows, macOS o Linux. Abre una terminal nueva después de instalar: las terminales antiguas pueden conservar un PATH anterior.

Comprueba `java --version` y `javac --version`. Si el primer comando funciona pero el segundo no, revisa que instalaste un JDK y no solo un entorno de ejecución. `JAVA_HOME` debe apuntar al directorio del JDK, no a su carpeta `bin`. La variable PATH debe permitir encontrar las herramientas. No necesitas instalar Java para los ejemplos compatibles del playground.
