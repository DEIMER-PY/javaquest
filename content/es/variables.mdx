Una variable tiene un nombre, un tipo y un valor. `int edad = 20;` declara un entero. `double` representa números decimales de punto flotante; `boolean` representa true o false, y `char` un carácter entre comillas simples. `String` es una clase para texto.

Java comprueba los tipos al compilar. Una variable `int` no puede recibir directamente el texto "veinte". Usa nombres descriptivos en camelCase y separa declaración de asignación cuando sea útil. `final` impide reasignar una variable, pero no convierte automáticamente un objeto mutable en inmutable.

## Observa y ejecuta

```java
public class Main {
    public static void main(String[] args) {
        int edad = 20;
        boolean estudiante = true;
        System.out.println(edad + " / " + estudiante);
    }
}
```
