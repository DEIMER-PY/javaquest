Un error de sintaxis impide compilar. Una excepción interrumpe una ejecución. Un error lógico produce un resultado incorrecto sin necesariamente mostrar mensajes. Aprende a distinguirlos.

Reduce el ejemplo, anota la entrada y la salida esperada y observa valores intermedios con println. Lee el primer error del compilador. En el IDE local usarás puntos de interrupción para revisar el programa paso a paso.

## Observa y ejecuta

```java
public class Main {
    public static void main(String[] args) {
        int a=5, b=2;
        System.out.println("a=" + a + ", b=" + b);
        System.out.println((double) a / b);
    }
}
```

## Tu misión

Corrige el promedio entero de 5 y 2 para obtener 3.5.

## Antes de continuar

Predice la salida antes de ejecutar. Luego cambia un valor, explica el resultado y compara con tu predicción. Si aparece un error, identifica su línea y corrige primero la causa inicial.
