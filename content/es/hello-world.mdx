Una clase agrupa código. En este ejemplo, `public class Main` define una clase llamada Main. Su archivo se llama `Main.java`: Java distingue mayúsculas y minúsculas. Las llaves delimitan bloques y las instrucciones suelen terminar con punto y coma.

`public static void main(String[] args)` es el punto de entrada tradicional. `System.out.println` escribe en la salida estándar y agrega un salto de línea. Los textos llevan comillas dobles. Cuando hay un error, lee primero el mensaje y la línea indicada: una comilla o llave faltante puede generar varios errores posteriores.

## Observa y ejecuta

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hola, mundo");
    }
}
```
