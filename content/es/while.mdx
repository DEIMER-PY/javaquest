`while` comprueba una condición antes de cada repetición. Si empieza siendo falsa, el bloque no se ejecuta. Una variable de control debe acercarte al final; olvidarla puede crear un ciclo infinito.

`do-while` comprueba al final y ejecuta al menos una vez. Para menús locales puede ser útil. En el playground puedes detener la ejecución; diseña primero la condición de salida.

## Observa y ejecuta

```java
public class Main {
    public static void main(String[] args) {
        int cuenta = 1;
        while (cuenta <= 3) {
            System.out.println(cuenta);
            cuenta++;
        }
    }
}
```

## Tu misión

Imprime una cuenta regresiva desde 5 hasta 1.
