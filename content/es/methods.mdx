Un método agrupa una tarea con un nombre. Puede recibir parámetros y devolver un valor. Define una responsabilidad clara: calcular un promedio es distinto de mostrar un menú.

`static` permite llamar este método desde main sin crear un objeto. Más adelante usarás métodos de instancia. Evita copiar bloques repetidos: extraer un método facilita entender y comprobar la lógica.

## Observa y ejecuta

```java
public class Main {
    static void saludar() { System.out.println("Hola"); }
    public static void main(String[] args) { saludar(); }
}
```
