`for` reúne inicio, condición y actualización: `for (int i=0; i<3; i++)`. La actualización ocurre después de cada vuelta. Su variable puede quedar limitada al bloque.

Usa `<` cuando recorres índices de 0 a longitud menos uno. `<=` suele causar un acceso fuera de rango. Un `for-each` simplifica recorrer valores cuando no necesitas el índice.

## Observa y ejecuta

```java
public class Main {
    public static void main(String[] args) {
        for (int i=1; i<=5; i++) {
            System.out.println(i * 2);
        }
    }
}
```
