Java nació en Sun Microsystems con James Gosling y su equipo. El proyecto empezó en 1991 con el nombre Oak y Java se presentó públicamente en 1995. Buscaban un lenguaje portable para dispositivos; con el tiempo se convirtió en una herramienta importante para aplicaciones empresariales.

Hoy encontrarás Java en servicios backend, sistemas financieros, herramientas de escritorio y parte del ecosistema Android. La idea de «escribir una vez, ejecutar en distintos sistemas» se apoya en el bytecode y una JVM compatible. Java y JavaScript son lenguajes distintos: compartir parte del nombre no los hace intercambiables.
