Los operadores `+`, `-`, `*`, `/` y `%` permiten calcular. Cuando ambos operandos son enteros, la división descarta la parte fraccionaria: `5 / 2` da 2. Con `5.0 / 2` obtienes 2.5. `%` devuelve el resto y ayuda a detectar números pares.

Los paréntesis expresan intención y controlan la prioridad: `(2 + 3) * 4` no equivale a `2 + 3 * 4`. Dividir un entero entre cero causa una excepción. `double` tiene precisión limitada; para dinero real estudiarás `BigDecimal`. No interpretes una suma con decimales como aritmética exacta en todos los casos.

## Observa y ejecuta

```java
public class Main {
    public static void main(String[] args) {
        System.out.println(5 / 2);
        System.out.println(5.0 / 2);
        System.out.println(8 % 2);
    }
}
```
