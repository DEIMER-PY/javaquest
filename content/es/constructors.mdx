Un constructor inicializa un objeto. Tiene el nombre de la clase y no declara tipo de retorno. Si declaras un constructor, Java no añade automáticamente el constructor vacío.

`this` se refiere a la instancia actual. En `this.nombre = nombre`, la izquierda es el atributo y la derecha el parámetro. Valida los datos al crear el objeto para evitar estados inválidos desde el principio.

## Observa y ejecuta

```java
class Persona {
    String nombre;
    Persona(String nombre) { this.nombre=nombre; }
}
public class Main {
    public static void main(String[] args) { System.out.println(new Persona("Ada").nombre); }
}
```
