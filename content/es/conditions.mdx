`if` ejecuta un bloque cuando una condición booleana es verdadera. `else` representa la alternativa. Usa operadores de comparación como `>=` y combina condiciones con `&&` (ambas) o `||` (alguna).

Evalúa casos frontera: para edad mínima 18, prueba 17, 18 y 19. `=` asigna; `==` compara valores primitivos. Las llaves evitan ambigüedad al añadir instrucciones.

## Observa y ejecuta

```java
public class Main {
    public static void main(String[] args) {
        int edad = 18;
        if (edad >= 18) {
            System.out.println("Mayor de edad");
        } else {
            System.out.println("Menor de edad");
        }
    }
}
```
