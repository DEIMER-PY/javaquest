A variable has a name, type, and value. `int age = 20;` declares an integer. `double` represents floating-point numbers, `boolean` true or false, and `char` a character in single quotes. `String` is a class for text.

Java checks types during compilation. An `int` cannot directly receive the text "twenty". Use descriptive camelCase names. `final` prevents variable reassignment, but does not automatically make a mutable object immutable.

## Observe and run

```java
public class Main {
    public static void main(String[] args) {
        int edad = 20;
        boolean estudiante = true;
        System.out.println(edad + " / " + estudiante);
    }
}
```
