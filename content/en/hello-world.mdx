A class groups code. `public class Main` defines a class named Main, stored in `Main.java`: Java is case-sensitive. Braces delimit blocks and statements commonly end with a semicolon.

`public static void main(String[] args)` is the traditional entry point. `System.out.println` writes to standard output and adds a newline. Text uses double quotes. When an error occurs, read the first message and its line number: a missing quote or brace can cause multiple later errors.

## Observe and run

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hola, mundo");
    }
}
```
