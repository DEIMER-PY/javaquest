Java began at Sun Microsystems with James Gosling and his team. Work started in 1991 under the name Oak, and Java was publicly introduced in 1995. The team sought a portable language for devices; it later became an important tool for enterprise applications.

Today Java powers backend services, financial systems, desktop tools, and part of the Android ecosystem. Its portability relies on bytecode and a compatible JVM. Java and JavaScript are different languages: their names do not make them interchangeable.
