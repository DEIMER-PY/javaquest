Install a JDK from an official provider such as Eclipse Temurin. Use JDK 21 for this path's local projects and consult the tools guide for Windows, macOS, or Linux. Open a new terminal after installation: older terminals may retain the previous PATH.

Check `java --version` and `javac --version`. If only the first works, verify you installed a JDK. `JAVA_HOME` points to the JDK directory, not its `bin` folder. PATH must make the tools discoverable. Compatible playground examples do not require a local Java installation.

## Observe and run

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Listo para aprender");
    }
}
```

## Your mission

Check both versions in your terminal, then run the example.

## Before moving on

Predict the output before running. Then change a value, explain the result, and compare it with your prediction. If an error appears, locate its line and fix the initial cause first.
