Operators `+`, `-`, `*`, `/`, and `%` perform calculations. Integer division discards the fractional part: `5 / 2` is 2. `5.0 / 2` yields 2.5. `%` returns the remainder and helps identify even numbers.

Parentheses express intent and control precedence: `(2 + 3) * 4` differs from `2 + 3 * 4`. Integer division by zero throws an exception. `double` has limited precision; for real money you will later study `BigDecimal`.

## Observe and run

```java
public class Main {
    public static void main(String[] args) {
        System.out.println(5 / 2);
        System.out.println(5.0 / 2);
        System.out.println(8 % 2);
    }
}
```
