`for` combines initialization, condition, and update: `for (int i=0; i<3; i++)`. The update runs after each iteration. Its variable can remain scoped to the block.

Use `<` when traversing indexes from 0 to length minus one. `<=` often causes an out-of-range access. A for-each loop simplifies traversing values without an index.

## Observe and run

```java
public class Main {
    public static void main(String[] args) {
        for (int i=1; i<=5; i++) {
            System.out.println(i * 2);
        }
    }
}
```
