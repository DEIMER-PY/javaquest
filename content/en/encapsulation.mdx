Encapsulation controls internal details. Declare fields private and expose operations preserving rules. Adding setters to everything is not enough: decide which changes should be allowed.

An account must reject negative deposits. A deposit method validates the amount before changing balance. Getters expose state without direct mutation.

class Cuenta {
    private int saldo;
    void depositar(int monto) { if(monto<=0) throw new IllegalArgumentException("Monto inválido"); saldo+=monto; }
    int getSaldo() { return saldo; }
}
public class Main {
    public static void main(String[] args) { Cuenta c=new Cuenta(); c.depositar(10); System.out.println(c.getSaldo()); }
}
