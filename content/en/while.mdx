`while` checks a condition before every iteration. If it starts false, the body never runs. A control variable must move toward termination; forgetting it can create an infinite loop.

`do-while` checks afterward and runs at least once, which can help with local menus. You can stop the playground, but design the exit condition first.

## Observe and run

```java
public class Main {
    public static void main(String[] args) {
        int cuenta = 1;
        while (cuenta <= 3) {
            System.out.println(cuenta);
            cuenta++;
        }
    }
}
```
