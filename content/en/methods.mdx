A method names a task. It can receive parameters and return a value. Give it a clear responsibility: calculating an average differs from displaying a menu.

`static` lets main call this method without creating an object. Later you will use instance methods. Extract repeated logic to make it easier to understand and verify.

## Observe and run

```java
public class Main {
    static void saludar() { System.out.println("Hola"); }
    public static void main(String[] args) { saludar(); }
}
```
