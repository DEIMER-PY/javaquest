An array stores a fixed number of same-type elements. `int[] marks = {7,8,9};` has indexes 0, 1, and 2. Its `length` property has no parentheses.

Reading index 3 throws an exception. Empty arrays are valid but have no first element. Check that indexes fall between zero and length minus one.

## Observe and run

```java
public class Main {
    public static void main(String[] args) {
        int[] notas={7,8,9};
        System.out.println(notas[0]);
        System.out.println(notas.length);
    }
}
```

## Your mission

Create an array of three names and print the last.
